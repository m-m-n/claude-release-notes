# Task Plan: task0001 — Markdown-preserving translation instruction

## Goal

The claude-batch translation prompt explicitly instructs the model to keep
Markdown syntax and structure unchanged, so downstream rendering can rely on
the translated body still being Markdown.

## Requirements

FR3

## Scope

### Files to Create
- (none)

### Files to Modify
- `internal/translate/claudebatch.go` — extend the fixed prompt instruction
- `internal/translate/claudebatch_test.go` — assert the new instruction text

## Design

Extend the fixed instruction preamble (the constant sent ahead of every
section) with a directive that: the section content is Markdown; its syntax
and structure (headings, list markers, inline code, bold, links, fenced
code blocks) must be reproduced unchanged; only the human-readable text is
translated; content inside inline code and fenced code blocks is left
untranslated. No signature, delimiter, or splitting behavior changes.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: The assembled prompt contains the Markdown-preservation
      directive (structure unchanged, translate text only, code content
      untranslated).
- [ ] AC-2: All existing prompt/delimiter/splitting tests still pass
      unchanged (no contract drift).

## Test Notes

AC-1 extends the existing prompt-content test. AC-2 is the existing suite.
No subprocess behavior changes, so the fake-runner tests are untouched.

## Out of Scope

- Any rendering work (task0002). Any change to Translate's signature,
  delimiter protocol, or error handling.
