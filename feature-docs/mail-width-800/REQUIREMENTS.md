# メールカード幅 800px の実装反映 - 要件定義書

## 1. 概要

### 1.1 背景

実機で届いたメールの確認後、/em-workflow:design にてメールカードの幅を
max-width 600px から 800px へ広げる決定が行われ、デザイン成果物
（feature-docs/release-notes-fetcher/DESIGN.md およびモック）は更新済み。
実装側のメールテンプレートは 600px のままであり、乖離が生じている。

### 1.2 目的

実装をデザイン決定（max-width 800px）に一致させる。

### 1.3 スコープ

- `internal/mail/build.go` の digest テンプレートのコンテナ幅変更
- 幅に言及する既存テスト・コメントの追随更新

スコープ外: パレット・タイポグラフィ・スペーシング等その他のスタイル値
（反映済みのため変更しない）。

## 2. ビジネス要件

### 2.1 対象ユーザー

| ユーザータイプ | 説明 |
|----------------|------|
| メール受信者（本人） | 配信されたリリースノートダイジェストを Gmail で読む |

### 2.2 期待される効果

- デスクトップの閲覧ペインで本文の行が広く使われ、読みやすくなる

## 3. ユースケース

### UC01: 800px 幅のダイジェスト受信

**アクター**: メール受信者

**基本フロー**:
1. 定期実行が新規リリースを検出しメールを送信する
2. 受信メールのコンテンツカードが最大 800px 幅で表示される

**事後条件**:
- カード幅以外の見た目は従来と同一

## 4. 機能要件

### 4.1 機能一覧

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | カード幅 800px | digest HTML のコンテナ `max-width` を 800px にする | 高 |

### 4.2 機能詳細

#### F01: カード幅 800px

**説明**: `internal/mail/build.go` の digestTemplate 内コンテナ div の
インラインスタイル `max-width:600px` を `max-width:800px` に変更する。
`max-width` 指定のため、狭い画面では従来どおり自然に折り返される。

## 5. 非機能要件

- 幅以外のインラインスタイル値（色・フォントサイズ・行間・余白）を
  変更しない
- 依存関係の追加なし

## 6. 成功基準

### 受け入れ基準

- [ ] 生成される digest HTML のコンテナが `max-width:800px` である
- [ ] `max-width:600px` が digest HTML に残っていない
- [ ] `go test ./...` が全て成功する

## 7. テストシナリオ

- [ ] 正常系: Build の出力 HTML に `max-width:800px` が含まれる
- [ ] 回帰: 既存のメール構成テスト（件名・本文・エスケープ）が変更なしで通る
