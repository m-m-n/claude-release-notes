# Task Plan: task0004 — claude-batch translation wrapper

## Goal

A `translate` package that turns a batch of English release-note bodies into
Japanese via one `claude-batch` subprocess call, recovering per-release
sections reliably.

## Requirements

FR4

## Scope

### Files to Create
- `internal/translate/claudebatch.go` — translator type, prompt assembly,
  subprocess invocation, output re-splitting
- `internal/translate/claudebatch_test.go` — unit tests
- `go.mod` — only if absent in the worktree, per IMPLEMENTATION.md "Module
  identity" (standard library only)

### Files to Modify
- (none)

## Design

Implements the `translate.Translator` contract in IMPLEMENTATION.md Shared
Components. Behavior:

1. Invocation: run the configured command name (default `claude-batch`) with
   the single argument `-`; the full prompt goes to stdin; the translation
   is read from stdout. The `-p` flag is forbidden (SPEC constraint).
2. Prompt: a Japanese translation instruction followed by every section,
   each wrapped in unambiguous per-section delimiter markers the instruction
   tells the model to preserve in its answer. Markers must be chosen so they
   cannot plausibly occur inside release-note text.
3. Output recovery: split stdout by the delimiter markers back into exactly
   one translated text per input section, order preserved, surrounding
   whitespace trimmed.
4. Errors (all abort, per NFR4): subprocess non-zero exit (stderr excerpt
   included in the error), empty stdout, marker count mismatch, or any
   section unrecoverable.
5. The command name is injectable so tests substitute a fake executable /
   runner instead of the real claude-batch.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: The assembled prompt contains the instruction, every input
      section, and one pair of delimiters per section, in input order.
- [ ] AC-2: A well-formed fake response is split into the same number of
      translations, in order, with delimiters and padding whitespace
      removed.
- [ ] AC-3: Subprocess non-zero exit yields an error; no translations are
      returned.
- [ ] AC-4: Empty stdout yields an error.
- [ ] AC-5: A response missing one section's delimiters yields an error
      (never a silently shorter result).
- [ ] AC-6: The subprocess is invoked with exactly the argument `-` and the
      prompt on stdin (asserted via the fake runner).

## Test Notes

All unit tests via an injected fake runner (or a stub executable in
t.TempDir()); the real claude-batch is never executed. AC-5 is the critical
edge case from SPEC.md.

## Out of Scope

- Deciding WHAT to translate (release selection — task0006).
- HTML rendering of translations (task0005).
