# Task Plan: task0003 — GitHub Releases client

## Goal

A `github` package that fetches `anthropics/claude-code` releases via the
GitHub REST API with token auth, exposing "latest release" and "all releases
newer than X" queries.

## Design

Implements the `github.Client` contract in IMPLEMENTATION.md Shared
Components. Behavior:

1. Endpoint: the releases listing for `anthropics/claude-code`
   (`/repos/anthropics/claude-code/releases`) with per-page sizing and page
   parameters; base URL injectable so tests point at a local test server.
2. Every request carries the token as a Bearer authorization header and the
   GitHub JSON Accept header.
3. Fields consumed per release: tag name, body, published-at, draft,
   prerelease. Draft and prerelease entries are filtered out everywhere.
4. `Latest()`: first non-draft, non-prerelease entry in the listing
   (API returns reverse-chronological order); none found after exhausting
   pagination → error.
5. `Since(version)`: walk pages newest→oldest collecting filtered releases
   until an entry with tag name equal to `version` is met (stop, exclusive)
   or pagination ends (all collected — the SPEC edge case of a version no
   longer listed). Result is newest first.
6. Non-2xx response → error including the HTTP status but never the token.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: Since returns exactly the releases newer than the stored
      version, newest first, across a multi-page mocked listing.
- [ ] AC-2: Draft and prerelease entries never appear in Latest or Since
      results.
- [ ] AC-3: Since with the stored version as the newest listing entry
      returns an empty slice.
- [ ] AC-4: Since with a version absent from the listing returns all listed
      (filtered) releases.
- [ ] AC-5: Latest returns the newest filtered release.
- [ ] AC-6: Requests carry the Bearer token and Accept headers (asserted by
      the mock server).
- [ ] AC-7: A non-2xx API response yields an error containing the status
      but not the token value.

## Test Notes

Unit tests with a local HTTP test server serving canned paged JSON; no real
network. Pagination across ≥ 2 pages is the core case (AC-1). AC-7 uses a
sentinel token value asserted absent from the error text.
